# 💎 Glow Empire — Expérience numérique premium immersive

Site web premium de personal branding, pensé comme une **expérience cinématique** plutôt qu'un site vitrine classique. Univers bleu abyssal, diamant 3D lumineux, storytelling par le scroll.

> Projet client réel — direction artistique haut de gamme, animation avancée, mobile-first.

---

## 🎯 L'objectif

Ne pas construire "un site de plus", mais une **entrée dans un univers**. Le site présente un protagoniste (personal branding), son entreprise, ses livres — avec une seule consigne : transmettre prestige, contrôle, mystère et puissance à chaque interaction.

**Inspirations assumées** : Apple, Linear, Stripe, Raycast, sites Awwwards immersifs — sans jamais copier, avec une identité propre.

## ✨ Ce qui rend l'expérience premium

- 💎 **Diamant 3D interactif** — Rendu Three.js/TresJS, pièce centrale de l'identité visuelle
- 🎬 **Scroll cinématique** — Sections qui se chevauchent progressivement, sensation de profondeur et de progression
- 🌊 **Smooth scroll** — Lenis pour une fluidité totale, aucune saccade
- ✨ **Animations avancées** — GSAP + Motion pour des transitions maîtrisées, jamais agressives
- 🪟 **Glassmorphism premium** — Panneaux et boutons liquides sur-mesure
- 📱 **Mobile-first** — Menu radial flottant custom, pensé pour l'usage réel
- 💳 **Paiement intégré** — KKiaPay pour les transactions liées aux livres/produits

## 🎨 Identité visuelle

Univers **bleu abyssal + diamant lumineux + futurisme maîtrisé**.

```
Fond principal    #010B19
Fond secondaire   #021833
Glow intermédiaire #0052A3
Glow lumineux     #00A3FF
Diamant sombre    #0E3975
```

Le luxe visuel vient de l'espace, du rythme, des transitions et de la lumière — jamais de la surcharge.

## 🏗️ Stack technique

- **Framework** : Vue 3 (Composition API, `<script setup>`)
- **Build** : Vite 8 + Tailwind CSS v4
- **3D** : TresJS + Three.js (diamant interactif)
- **Animation** : GSAP + Motion (Vue)
- **Scroll** : Lenis (smooth scroll)
- **UI** : Swiper (carrousels), Phosphor Icons
- **Paiement** : KKiaPay SDK

## 🧭 Principes de design non-négociables

- Jamais d'esthétique "template IA" ou SaaS générique
- Jamais d'animation excessive ou agressive — la retenue fait le luxe
- Chaque composant est customisé, aucun élément générique
- Le mouvement doit toujours raconter quelque chose, jamais gratuit
