# Glow Empire — Philosophie de Design

Glow Empire n'est pas un simple site vitrine.

Le site doit ressembler à une expérience numérique premium et immersive.
L'utilisateur ne doit pas avoir l'impression de consulter un site web classique.

Le site doit transmettre :
- du prestige,
- du contrôle,
- du mystère,
- de la puissance,
- de la vision,
- une sensation d'empire numérique.

L'expérience doit être cinématique.

Le mouvement, le scroll, la lumière et l'espace doivent raconter quelque chose.

Le site doit donner l'impression d'entrer dans un univers.

Le design doit être :
- moderne,
- minimaliste,
- futuriste,
- élégant,
- respirant,
- maîtrisé.

Éviter :
- les interfaces surchargées,
- les couleurs agressives,
- les animations excessives,
- les effets “template IA”,
- les composants trop génériques.

Le luxe visuel doit venir de :
- l'espace,
- le rythme,
- les transitions,
- les lumières,
- la profondeur,
- la retenue.

Le site doit principalement être pensé mobile-first.

Le comportement du scroll est très important.
Le site doit donner une sensation de profondeur et de progression.

Les sections doivent se chevaucher progressivement pendant le scroll.
Quand une nouvelle section arrive, elle passe au-dessus de la précédente.
Quand l'utilisateur remonte, les sections redescendent naturellement.

Le site doit ressembler à :
- une expérience immersive,
- une interface premium futuriste,
- un storytelling interactif.

Le site doit s'inspirer de :
- Apple,
- Linear,
- Stripe,
- Raycast,
- certains sites Awwwards immersifs.

Mais sans copier directement.

Le site doit avoir sa propre identité.

L'identité visuelle principale est :
- un univers bleu abyssal,
- un diamant lumineux,
- des reflets cristallins,
- une ambiance premium futuriste.
