```md
# Glow Empire — Principes UI

L'interface doit être minimaliste mais puissante.

Chaque élément doit avoir une intention.

Éviter les composants inutiles.

Éviter les interfaces surchargées.

L'espace vide est très important.

Le site doit respirer.

Le spacing doit être généreux.

Les grandes zones vides sont encouragées.

La typographie est un élément central.

Les textes doivent être :
- lisibles,
- élégants,
- imposants,
- cinématiques.

Le site doit utiliser une hiérarchie typographique forte.

Le design doit mélanger :
- sophistication,
- technologie,
- luxe,
- futurisme.

Palette principale :

## Fonds
- #010B19
- #021833

## Glow et lumières
- #0052A3
- #00A3FF

## Diamant
- #0E3975
- #1D74E8
- #7AD3FF

## Contraste
- #001C3D
- #FFFFFF

Le bleu doit être utilisé avec retenue.

Le glow doit rester subtil.

Le site ne doit jamais devenir agressif visuellement.

Les bordures doivent être :
- fines,
- élégantes,
- discrètes.

Les coins arrondis doivent sembler organiques.

Les sections qui se chevauchent doivent donner une sensation de profondeur.

Desktop :
- navigation premium split autour du diamant,
- portrait sticky du protagoniste,
- storytelling à droite.

Mobile :
- expérience immersive,
- navigation flottante,
- sections simplifiées,
- priorité à la fluidité.

Le site doit éviter l'esthétique “frontend IA générique”.

Éviter :
- Lucide icons,
- composants génériques non modifiés,
- UI trop SaaS classique.

Préférer :
- Phosphor Icons,
- Iconoir,
- composants fortement customisés.

Typographies recommandées :

## Titres
- Clash Display
- Cabinet Grotesk
- Neue Montreal

## Textes
- General Sans
- Switzer

Le site doit toujours sembler :
- premium,
- maîtrisé,
- cohérent,
- cinématique.
```
