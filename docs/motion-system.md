# Glow Empire — Motion System

Le mouvement est l'élément principal de l'expérience.

Le site doit être fluide, vivant et cinématique.

Les animations ne doivent jamais sembler robotiques.

Le mouvement doit guider naturellement l'attention.

Les transitions doivent être :
- lentes,
- élégantes,
- fluides,
- organiques.

Le motion design doit transmettre :
- du contrôle,
- du prestige,
- de la sophistication.

Éviter les animations brutales.

Éviter les animations trop rapides.

Éviter les animations gadgets.

Le scroll doit devenir une timeline cinématique.

Le site doit utiliser :
- pinned scrolling,
- layered scrolling,
- cinematic transitions,
- subtle parallax,
- staggered reveals,
- floating motion.

Le diamant 3D est l'élément narratif principal du site.

Le diamant doit :
- tourner lentement,
- réagir au scroll,
- rester élégant,
- rester lisible,
- ne jamais être agressif visuellement.

Le diamant doit donner une sensation :
- de puissance,
- de technologie,
- de mystère,
- d'artefact futuriste.

Le scroll principal du site fonctionne comme ceci :

1. Hero minimal et mystérieux.

2. Arrivée progressive du diamant à la frontière entre la section 1 et la section 2.

3. Pendant le scroll, le diamant monte progressivement.

4. Quand le diamant atteint le haut de l'écran :
- il devient sticky,
- il reste visible,
- il continue sa rotation liée au scroll.

5. Sur desktop :
- la navigation apparaît progressivement autour du diamant.

6. Sur mobile :
- le menu reste flottant dans une bulle séparée.

Le menu mobile doit être :
- radial,
- flottant,
- minimaliste,
- premium.

Le bouton mobile doit ouvrir les éléments de navigation sur un arc de 90 degrés.

Le glassmorphism doit être premium.

Le rendu recherché n'est pas un simple blur.

Le rendu recherché est :
- liquide,
- réfracté,
- organique,
- translucide,
- légèrement déformant.

Les boutons CTA doivent ressembler à du verre liquide premium.

Le hero doit contenir :
- une vidéo atmosphérique,
- lente,
- sombre,
- mystérieuse,
- futuriste.

La vidéo doit rester discrète.

Le texte doit rester prioritaire.

Le footer doit ressembler à une fin de film.

Le footer doit contenir :
- une vidéo de fond discrète,
- un statement premium,
- une navigation élégante,
- une hiérarchie propre.

Les animations doivent créer du rythme.

Le site doit alterner :
- moments calmes,
- moments impactants.

L'utilisateur doit constamment ressentir :
"Je veux voir la suite."
